A permutation is a set of closed journeys: follow each position to its value.

Try an example

1. Read position → value

Choose a position below, then follow its arrows. Each color identifies one cycle; a dashed loop marks a fixed point.

2. Spot the fixed points

A 1-element cycle (i) means position i contains i. So a permutation is fixed-point-free exactly when every cycle has at least 2 elements.

3. Build it with swaps

A cycle of length k needs k − 1 swaps. Step through a shortest path from identity to your permutation. Each step swaps the values at two positions.

Why is this minimal? Identity has n cycles. One swap changes the number of cycles by exactly 1, so reaching c cycles requires at least n − c swaps. This construction achieves that bound.

Back to the graph layers

FPF permutations can first appear at layer ⌈n/2⌉ (for n ≥ 2): without singleton cycles, there can be at most ⌊n/2⌋ cycles. The last layer, n − 1, contains one n-cycle and is entirely FPF when n ≥ 2. For n = 1, the identity is the only permutation and is not FPF.
