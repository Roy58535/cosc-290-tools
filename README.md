# COSC 290 Tools

## Description

This repository is a collection of lightweight visualization tools for Colgate University COSC 290 Discrete Structures course. The tools are built with codex.

## Architecture

Each sub-directory contains a small tool for a problem / illustration.

## Tool List

### Permutations, Swaps, Cycles and FPF

`fpf` is a tool for visualizing permutations, swaps and cycles regarding permutations, and how FPF permutations are related.
